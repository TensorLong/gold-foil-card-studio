# gold-foil-card-studio

A Claude Code skill that turns a theme or reference image into an editable gold-foil card: aligned line art drives a Blender reflection-sweep material that produces angle-dependent shine, multi-angle renders, and an optional web port.

Layout: `SKILL.md` (workflow), `references/` (method, config example, web port), `scripts/` (Blender build + smoke test), `agents/` (agent manifest), `assets/` (web renderer, license).
