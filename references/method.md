## 可复现的连接

在同一张卡面上采样彩色图和线稿，不另设有深度偏移的发光平面：

```text
Texture Coordinate.Reflection → Mapping ──────────────────┐
Texture Coordinate.UV → Noise.Fac → Multiply(noiseAmount) ─┤
                                                        Add
                                                         ↓
                          Add(phase) → Multiply(repeat) → Ping-Pong(1)
                                                         ↓
                                                Color Ramp → S

lineart（Non-Color、白底黑线）→ 反相 Color Ramp → L
artwork（sRGB）→ Principled BSDF → Print
goldColor + emissionStrength → Emission → Gold

Mix Shader(L, Print, Gold) → GoldDetail
Mix Shader(S, Print, GoldDetail) → Material Output
Render Layers → Glare / Fog Glow → Composite
```

全金共同母版模式：artwork 与 lineart 同源黑白 PNG，均作为 Non-Color 读取；artwork → `Color Ramp(ink,stock)` → Principled Base Color。`printPalette` 是可选的静态金色印刷配色，不修改 `S×L`，也不是将彩色成品套 CSS 金色滤镜。例：`{"ink":[0.16,0.075,0.013],"stock":[0.68,0.48,0.18]}`。

平卡配正交相机时，每个点的反射方向相同，容易变成全卡同步闪烁。默认使用透视相机以产生跨卡面的空间光带；映射旋转、相机距离与视角共同影响光带宽度。

两个混合等价于使用 `S × L` 混合 Print 与 Gold，但保留两级节点方便分别检查。白色线稿背景得到 `L=0`；黑色线条得到 `L=1`。不要把纯白背景当成需要烫金的区域。

Mapping 的向量进入数学节点时，Blender 隐式取三通道平均；迁移到 GLSL/Metal 时要显式求平均，不要改成只取 X、向量长度或点乘法向。`Ping-Pong` 是周期为 2、峰值为 1 的三角波；不等同于简单 `fract` 锯齿。

## 旋钮

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `mappingRotation` | `[0,0,32]` 度 | 光带方向，Blender 脚本转弧度 |
| `phase` | `0` | 移动光带，优先用它调整正面的亮暗位置 |
| `repeat` | `6` | 光带重复数；正值，不是动画速度 |
| `noiseScale` / `noiseAmount` | `600` / `-0.2` | 颗粒细度与对扫光边缘的扰动 |
| `sweepBlack` / `sweepWhite` | `0.5` / `0.82` | 黑白渐变范围；白点越靠近 1，亮部越窄 |
| `lineBlack` / `lineWhite` | `0.08` / `0.35` | 黑线提亮、白底压黑；过宽会吞掉细节 |
| `color` | `[1,0.72,0.22]` | 线性 RGB，暖金色；不是十六进制 sRGB |
| `emission` | `8` | 金线发光强度；先控制曝光再考虑加大 |

彩色图使用非金属、较粗糙的印刷 BSDF；金色轮廓使用发光模拟，卡片边缘用金属材质。这是视频式风格化方案，不宣称准确模拟真实金箔 BRDF。需要真实金属反射时可以把 Gold 分支换成金属 BSDF，但要明确这是另一种材质模型。

## 验收与交付

1. 两图（或共同母版）尺寸相同且不透明，线稿含黑线和白底。分别检查主体、背景、四边与文字，不要裁掉非主体区域。自动检查不能证明配准或视觉相似，必须目视检查。
2. 暂时看 S：转卡或换观察方向，光带相位必须变；固定卡片和相机时纹理不自行滚动。
3. 暂时看 L：纸面黑、线条白。恢复最终材质，扫光不能在空白处发亮。
4. 固定灯光、曝光和材质拍正面、左倾、右倾；检查金线位置变化及原画可读性。验证脚本另做同角度金光开/关对照，避免把几何变化误判成扫光。
5. `.blend` 中所有纹理已打包，关闭源文件夹后仍能打开。保留可编辑节点及旋钮，不仅交付 PNG。
